# Tyr launch kit

This directory contains launch copy, reproducible demonstrations, and an evidence
ledger for Tyr's research-preview announcement.

## Editorial position

**Core claim:** Tyr explores what machine learning systems look like when Lean's
type system is part of the stack, not a wrapper around it.

The public story should lead with compile-time tensor invariants and then show
that the idea reaches practical workloads: training, differential equations,
model inference, and a general typed GPU language with CUDA code generation.
Hardware results remain measurements of named devices rather than properties of
the interface as a whole. Molecule generation, speech, and hybrid simulation
are supporting evidence, not separate launch messages.

## Quick verification

```bash
lake build BranchingFlowsContinuousTrain
# On the Event Skeleton branch:
lake build RunVanDerPolLeanPlot
./scripts/launch/run_local_showcase.sh
# Compiler and code-generation checks; this does not execute CUDA locally:
lake exe TestGPUDSL
```

Native GPU execution and weight-dependent demonstrations are kept out of the
local harness so it remains predictable. Their exact commands and evidence
boundaries are in `showcase.md` and `evidence.md`. One five-module CUDA suite
has been recorded on a named device; the local 49-test suite remains the
compiler and code-generation check.

Internal launch preparation is tracked under
[`dev/launch/`](../dev/launch/README.md), outside the public article.
